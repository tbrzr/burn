Privacy

Template. If you run this service, replace this page with your own policy and contact details.

  • Notes are encrypted in the browser. The server stores only ciphertext, a view counter and an expiry time.
  • In random-key mode the decryption key is in the link's #fragment, which browsers do not send to servers.
  • Notes are deleted when read, or when they expire.
  • The server keeps a salted hash of the creator's IP address for rate limiting and abuse blocking.
  • If payments are enabled, Stripe handles card details. The server stores an anonymous credit token.
